# Worked example: the FASTENER repository

How this project implements the method. Where the general skill and this file
differ, this file holds for FASTENER.

| general | FASTENER |
|---|---|
| methodology | `experiments/METHODOLOGY.md` |
| plan: protocol, questions, hypotheses, revisions | `experiments/HYPOTHESES.md` (*Protocol*, H0-H10, *Revisions*) |
| ledger and designs | `experiments/EXPERIMENTS.md`, managed by `experiments/experiment_ids.py` |
| decision log | `experiments/DECISIONS.md` (DEC-01 onwards, *By experiment*) |
| reports | `experiments/reports/<ID>/`, generated by `make_report.py`, written with the `experiment-report` skill |
| report list | `experiments/reports/LIST.md` |
| manifest, run ID, dirty-tree refusal | `experiments/provenance.py` (`provenance.Run`, `DirtyTreeError`, `NON_CODE_PATHS`) |
| method ID | algorithm ID `<arm>@<experiments commit>+<fastener clone commit>#<config>` |
| runs and monitoring | `run_sota.py`, `run_queue.py`, `monitor.py`; on Vega, sbatch with a test job first |
| job-log digest | `distill-logs` skill |

Project-specific points:

- Two repositories are pinned in every algorithm ID: this one and the
  untouched FASTENER clone in `fastener/` (DEC-01).
- The budget unit is unique model fits (DEC-04), with wall clock beside it.
- The protocol is fixed in `HYPOTHESES.md`: one classifier for every method,
  seeds 2020-2024, a 60/20/20 split with `SPLIT_SEED = 20200`, AUF at K = 10.
- **Research questions** (`Q<n>`) are not yet supported by
  `experiment_ids.py`, whose `EXPERIMENT_RE` accepts only `H<n>` IDs. Extend
  it and commit that change before the first `Q` experiment. Do not tag a
  question's runs with an `H` ID.
- `results/` stays out of git. Experiments are closed by committing
  `experiments/` only.
- Commits are authored by the PI only, with no assistant co-author line.
  Pushed history is never rewritten.
- Code is written and committed on the workstation and pushed. Vega pulls and
  runs it, and results come back via ssh and tar.
- Report figures are wide (landscape), with datasets along x.
