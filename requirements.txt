# Experiment harness requirements.
#
# NOTE: this deliberately does NOT `-r fastener/requirements.txt`. Upstream pins
# a 2020 stack (numpy==1.18.1, scikit-learn==0.22.2.post1, scipy==1.4.1) that
# (a) cannot be installed on the Python 3.11 used here, (b) predates
# `fetch_openml(parser=...)`, which datasets.py needs, and (c) contradicts the
# environment that actually produced everything in results/. That include also
# could not resolve from a fresh clone, since fastener/ is gitignored and is not
# present until you clone it yourself.
#
# Floors below are the versions recorded in
# results/20260916T123417Z_madelon_baseline/manifest.json -- the environment the
# committed baseline was run under. Lower bounds, not pins: nothing here is
# known to need an exact version, and pinning would make the file a fiction the
# moment anyone upgrades.

# --- core: required by every script ---
numpy>=2.0            # manifest: 2.4.6
scipy>=1.11           # manifest: 1.17.1
scikit-learn>=1.4     # manifest: 1.9.0; >=1.2 needed for fetch_openml(parser=)
joblib>=1.3           # imported directly by run_experiment.py
matplotlib>=3.8       # manifest: 3.11.1; comparison plots

# Not imported by experiment code, but provenance.environment() records its
# version into every manifest. Without it, manifests log "pandas": null.
pandas>=2.0           # manifest: 3.0.5

# --- optional: additional baselines in experiments/sota_baselines.py ---
# These ARE installed by a plain `pip install -r requirements.txt`. Each is
# imported lazily inside its own run_* function, so if you prefer a leaner
# install you can comment them out: the module and every other selector still
# work when they are absent, and only that one baseline fails.
#
# All three were exercised against the core stack above (numpy 2.4.6,
# scikit-learn 1.9.0, Python 3.11): fit and produced rankings without error.

# numpy bump as something to re-check rather than assume.
